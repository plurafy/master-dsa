# Master Data Structures and Algorithms
Quickly learn Data Structure and Algorithms through test driven coding.

## Commands

**1. Clone Repo**
```sh
git clone https://github.com/plurafy/master-dsa.git
```

**2. Install Packages**
```sh
# JavaScript
npm install

# Python
uv sync
```

**3. Run Tests**
```sh
# JavaScript
npm run test

# Python
uv run pytest
```
